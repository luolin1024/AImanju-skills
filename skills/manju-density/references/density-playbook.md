# 密度审计与压缩手法

## 审计口径

| 数 | 口径 |
|---|---|
| 推进信息点数 | 本场交给观众的新信息：改变局势、揭示因果、更新目标 |
| 新增钩子数 | 新悬念、新危机、新反转预告（承接旧钩子不算新增） |
| 纯氛围时长占比 | 无信息无钩子的氛围段落时长 ÷ 场次时长 |

- **注水场** = 信息点 0 且钩子 0。
- **低密度场** = 信息点 + 钩子合计 1，且时长 > 20 秒。

## 压缩手法

1. **删场**：注水场直接删；删后核对因果链（前后场仍能接上），断链就改并场。
2. **并场**：同功能相邻场合并，冲突并进一场打完，省掉重复进出场。
3. **交代换载体**：背景与规则改借嘴说（反派挑衅、围观议论顺带点破）或物证插入镜（协议、伤疤、转账记录），替换整段旁白。
4. **台词减字**：单句台词 ≤ 20 字为目标；长篇控诉拆成交锋短句；书面语换口语；角色已知信息双方不复述。
5. **钩子前移**：把下一场的钩子提到本场集尾抛出；集尾末句后留白压进 1 秒内。
6. **去小说化**：心理描写转成可拍画面（表情、动作、插入镜）；旁白只留开场速交前情与关键盘算两处。

## 节奏指标基准

| 指标 | 目标 | 来源 |
|---|---|---|
| 首句时间 | ≤ 3 秒（黄金三秒） | 本技能默认 |
| 钩子间隔 | ≤ 60 秒一抛 | 公式包优先，缺项回退拆解区间 |
| 集尾留白 | 末句后 < 1.2 秒 | 同上 |
| 集长区间 | 常规集 36–63 秒、首集加长 90–225 秒 | $short-drama-breakdown 同形态实测参考区间 |

改动前后各算一遍，写进 `项目开发/密度审计.md` 的对比表。

## 压缩的红线

- 保戏剧节拍：删时长删到反应拍为止，情绪重音（一秒上下的特写）保留；
- 台词减字减到信息不失真：数字、名字、关系三样一字不动；
- 每处改动可回退：审计文档里的处置记录就是回退清单。
