# 信息密度压缩

让观众停不下来 = 每一段都在推剧情或都在钩人：**信息点**推剧情，**钩子**拉期待，两样都不沾的段落就是注水。本技能审计并压缩剧本密度，把初稿压到公式节奏参数附近。

## 使用边界

- 基准单一事实源：节奏参数优先取 $manju-formula 公式包（钩子间隔、爽点间隔、集长区间）；公式缺项才回退 $short-drama-breakdown 拆解维度的同形态实测参考区间。
- 大幅改动后的节奏目标变更（集数增减、篇章重切）仍须创作者拍板，本技能只压密度不重排结构。
- 改动一律留痕：剧本回写 + 审计文档双落，方便回退。

## 工作流

### 1. 圈定范围与基准

写明：压哪几集（或全剧）、四项基准数值（首句时间、钩子间隔、集尾留白、集长区间——取公式包或回退区间）。

**完成标准**：范围清单 + 四项基准数值落纸。

### 2. 逐场密度审计

按 [密度审计](references/density-playbook.md) 给每场记三个数：推进信息点数、新增钩子数、纯氛围时长占比。信息点 0 且钩子 0 的场标为注水场。

**完成标准**：每场三数齐备，注水场全部标出。

### 3. 执行压缩

按手法清单处置每个注水场与超重台词：删场 / 并场 / 交代换载体 / 台词减字 / 钩子前移 / 去小说化。每处改动记一行处置记录（位置 + 手法 + 前后时长估算）。

**完成标准**：每个注水场有处置记录；改动后各集时长估算落在基准集长区间内。

### 4. 密度复检

重算三数表与四项节奏指标，与基准并排对比；进不了区间的偏离项逐条注明理由（有意取舍）。

**完成标准**：四项指标进基准区间，或偏离项各有一条取舍理由。

### 5. 回写移交

改动写回剧本文件，改动清单与前后对比写 `项目开发/密度审计.md`，交 $short-drama-review 审查；节奏目标因此变更的，列出新目标请创作者拍板。

**完成标准**：剧本回写、密度审计.md 落盘、移交对象注明。
