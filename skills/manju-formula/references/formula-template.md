# 公式模板与最小可抄骨架

## 结构化公式格式

一行公式 + 变量表：

```
公式：<题材类型> × <主角身份：压位/藏牌> × <冲突引擎> × <反转机制> × <钩子节奏> × <爽点间隔> × <情绪配方>
```

| 变量 | 取值写法 | 依据写法 |
|---|---|---|
| 题材类型 | 战神 / 赘婿 / 重生复仇 / 系统流… | 拆解结论 |
| 主角身份 | 表层身份（被压位）+ 底牌（藏牌内容） | 底牌首次露面秒数 |
| 冲突引擎 | 反复制造冲突的机制（打脸循环 / 升级竞赛 / 误会驱动） | 各集冲突来源归纳 |
| 反转机制 | 反转类型与触发条件 | 集数 + 秒数 |
| 钩子节奏 | 多久抛一个新悬念、集尾卡点方式 | 实测钩子间隔 |
| 爽点间隔 | 相邻爽点最大间隔、单集爽点数 | 实测集数分布 |
| 情绪配方 | 压抑:释放配比、连环反转次数 | 分集统计 |

## 最小可抄骨架格式

beat 骨架，每行三段：`[位置] 功能 ｜ 填空变量`。变量用〈〉标出，换皮时逐个替换。

开篇骨架（首集，实测区间 90–225 秒）：

```
[0-10s]   当面施压，主角压位见底 ｜〈施压者〉〈压位事件〉
[10-30s]  底牌首次露面（半露，不揭底） ｜〈底牌形态〉
[30-90s]  首次反击小胜，围观改观 ｜〈反击手法〉
[90s+]    集尾卡点：更大的危机放话 ｜〈卡点台词性质〉
```

单集循环骨架（常规集，实测区间 36–63 秒）：

```
[开场] 承接上集钩子，第一拍直接入戏 ｜〈承接句〉
[前段] 新冲突进场 ｜〈冲突源〉
[中段] 压抑蓄力 ｜〈蓄力事件〉
[爽点] 反转 / 打脸释放 ｜〈爽点类型〉
[集尾] 新钩子卡点 ｜〈钩子性质〉
```

## 多部合并规则

- ≥2 部复现的 beat 写死为公式骨架；单部独有 beat 用〈个例：…〉占位，注明出处剧。
- 骨架行数即公式复杂度：骨架越短越通用，合并后超过 12 行说明在抄桥段而非提公式，回炉重压。
