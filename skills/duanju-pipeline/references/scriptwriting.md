# 编剧：原创剧本规范

## 生成提示词骨架（从核心思路卡片填入后使用）

> 你是一位 AI 短剧编剧，擅长在验证过的叙事骨架上做差异化表达。
>
> 任务：参照以下核心思路，创作一部全新短剧的第 1 集剧本。人物、世界观、具体冲突事件必须原创，目标剧中的角色名、专有名词、标志性场景一概不复用。
>
> 必须严格对齐（粘贴卡片五项）：
> - 开局钩子：{类型+描述}
> - 金手指机制：{类型+持续爽点来源}
> - 爽点节奏：3 秒内抛出情绪钩子；单集 60–90 秒；每 15–20 秒一个反转或信息增量；集尾停在"下一秒想看下一集"的悬念点
> - 核心关系轴：{对立结构}
> - 情绪落点：{观众消费的情绪}
>
> 原创自由区（自定并保持一致）：
> - 世界观/时代背景：{}
> - 主角设定：{性别、初始身份、一个鲜明性格标签}
> - 第 1 集核心冲突事件：{一句话}
>
> 输出格式：
> 1. 3 个备选剧名 + 一句话 logline；
> 2. 第 1 集完整剧本：〖场景〗/人物/动作神态（括注）/台词，外加制作标记 `[VO]` `[OS]` `[SFX]`；
> 3. 爽点节奏标注：行尾标 `【钩子】【反转】【悬念】`；
> 4. 后 3 集分集钩子（每集一句）。
>
> 情绪全部通过动作、神态、台词或环境细节外化呈现。

## 爽点节奏规范

- 第 1 拍（0–3 秒）：冲突动作、反常景象或强设定弹窗，直接抓人；开场即钩子，没有铺垫戏。
- 中段：每 15–20 秒一个反转或信息增量；两个反转之间必须有增量，间隔超 20 秒即视为注水，压缩或合并场景。
- 单集 60–90 秒；集尾停在情绪最高点或悬念刚揭一半处。

## 去小说化（可拍性红线）

目标状态：每一个情绪都由看得见、听得着的元素承载——动作、神态、台词、环境细节。心理活动只用 `[VO]` 一句带过或转成动作。

交稿前对成稿跑检查，命中行逐条改写为可拍动作或台词：

```bash
grep -nE "(心想|心中|暗道|暗想|暗暗|意识到|腹诽|喃道|自忖)" 剧集/EP001/剧本.md
```

## 原创红线（撞车检查）

拆骨时把目标剧的角色名、专有名词、金手指名称、标志性场景列成清单存入卡片；成稿后逐项 grep，零命中才算过检：

```bash
for t in 专名1 专名2 专名3; do grep -n "$t" 剧集/EP001/剧本.md; done
```

同题材同结构放行，情节逐场对应、专有名词复用一律重写。

## 定稿交接

过检的可拍稿交 `$short-drama-write`：按其标准格式（`# EP001 集名`、`## EP001-SC001 内·地点·时间`、对白与制作标记语法）整理写入 `剧集/EP001/剧本.md`。该技能的"能演的不说""开场直接接住局面"规则与本法线一致；时长核对用其 `duration_estimate.py --script 剧集/EP001/剧本.md --target-seconds 90`。
