# 拆骨：核心思路卡片框架

卡片是后续编剧的唯一对标物：参照卡片，参照它的情绪发动机；每张卡片对应一部目标剧。

## 卡片模板（复制到 `项目开发/核心思路卡片.md` 后逐项填写）

```markdown
# 核心思路卡片：《目标剧名》
拆解日期：YYYY-MM-DD｜证据来源：成片/公开资料链接

## 1. 开局钩子
类型：{背叛|羞辱|绝境|身份误解|强设定悬念|…}
描述：{前3–5秒/第一集抓住观众的核心情绪与画面}
证据：{第X集 00:12 画面/台词，或资料出处}

## 2. 金手指机制
类型：{系统|重生记忆|隐藏身份|特殊能力|规则漏洞|…}
持续爽点来源：{可复用性/升级空间/信息差保持方式}
证据：{…}

## 3. 爽点节奏
钩子：{第几秒出现，什么形态}
反转间隔：{实测每 15–20 秒还是更长；信息增量还是情绪增量}
集尾：{悬念形态与出现位置}
证据：{…}

## 4. 核心关系轴
对立结构：{至亲背叛|阶层压制|真假身份对立|规则 vs 普通人|…}
检验：{每一集的冲突如何挂回这条轴}

## 5. 情绪落点
观众消费的情绪：{被看见|翻身做主|智商碾压|守护珍贵之物|…}

## 换壳方案
{同一发动机的新壳：题材迁移/世界观替换/人物底色/金手指换型；新壳一句话}

## 制作参数（可选，有成片时由 $short-drama-breakdown 补齐）
集长：{…}｜镜长：{…}｜对白密度：{…}｜开场/集尾手法：{…}
```

## 五项判断问句（填写时逐项自问）

1. **开局钩子**——观众第 3 秒看到什么才停下滑动的手指？钩子是情绪（背叛/羞辱）还是设定（规则怪谈/弹窗）？
2. **金手指机制**——它凭什么持续制造爽点？一用就完的工具（单次解密）弱于可持续升级的工具（系统/重生记忆）。
3. **爽点节奏**——两个反转之间隔了几秒？间隔里是信息增量还是注水？集尾停在情绪最高点还是回落之后？
4. **核心关系轴**——把任意一集的冲突抽象一步，是否都挂回同一条对立轴？挂不回来说明拆错了轴。
5. **情绪落点**——追完一集观众带走的是哪种情绪？这部剧本质上在替观众完成什么心理补偿？

## 填写规则

- 每项必须带证据：集数+时间点（看过成片）或公开资料链接（没看过）；推断内容标注 `[推断]`。
- 拆逻辑不拆剧情：卡里出现目标剧专有名词的场合，仅限"证据"栏引用原文；其余栏目用类型词与抽象描述。
- 制作参数缺成片时按公开数据估计并标 `[推断]`，不空着——它是编剧环节定单集时长与节奏的输入。
- 复盘环节产出的迭代动作写回本卡片：改钩子设计、改换壳方案或改节奏目标。
