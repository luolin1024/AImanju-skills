# 短剧全链路管线

五个环节串成闭环：选品 → 拆骨 → 编剧 → 制作 → 复盘；复盘结论写回核心思路卡片，进入下一部剧的下一轮。拆骨拆的是"为什么有人追"，制作链解决"怎么拍出来"。

每部剧一个项目目录（由 `$short-drama` 初始化），管线文档与制作链文档同目录共存：

| 文档 | 产出环节 |
|---|---|
| `项目开发/爆款清单.md` | 选品 |
| `项目开发/核心思路卡片.md` | 拆骨 |
| `剧集/<EP>/剧本.md` | 编剧（经 `$short-drama-write` 定稿） |
| `制作成果/成片/` | 制作（`$short-drama-edit`） |
| `项目开发/数据复盘.md` | 复盘 |

## 入口规则

从任一环节进入时，先读上游文档；缺失或不完整时，用最小成本补齐（用户已有信息直接落盘即可），再进当前环节。全流程新建项目从选品开始。

## 1 选品（搜索爆款）

目标：锁定目标剧——一部"爽点逻辑你能驾驭、结构最清晰"的爆款，参照它的是可迁移的叙事骨架。

榜单源、检索式、表格与评级规范见 `references/market-scan.md`，联网检索后写入 `项目开发/爆款清单.md`。

完成标准（全部满足才算完）：
- 表格 ≥10 部（用户已锁定题材时 ≥5 部同题材），每部含剧名/题材/一句话卖点/可查热度/上线时间/出处链接；
- 每部标注"结构清晰度、爽点逻辑可驾驭度"两档评级；
- 目标剧已选定并写明理由；用户另有属意剧目时以用户为准，理由照记。

目标剧经用户确认后进入拆骨。

## 2 拆骨（分析爆款）

目标：产出核心思路卡片——去掉人名、地名、世界观后依然成立的情绪发动机。

按 `references/core-card.md` 的五项框架拆解，写入 `项目开发/核心思路卡片.md`。

完成标准：
- 五项全填：开局钩子 / 金手指机制 / 爽点节奏 / 核心关系轴 / 情绪落点，每项附目标剧证据（集数时间点或公开资料出处）；
- 已填"换壳方案"：同一情绪发动机装进什么新壳（题材迁移/世界观替换/人物底色/金手指换型）；
- 拿到目标剧成片或字幕时，加跑 `$short-drama-breakdown`，把集长/镜长/对白密度等制作参数并入卡片"制作参数"小节。

## 3 编剧（原创剧本）

目标：第 1 集可拍稿——情绪发动机严格对齐卡片，壳完全原创。

提示词骨架、爽点节奏规范、去小说化与原创红线见 `references/scriptwriting.md`。成稿后交 `$short-drama-write` 整理成 `剧集/EP001/剧本.md` 标准格式。

完成标准：
- 卡片五项逐项对齐，每项能在剧本中指出对应场次或台词；
- 原创红线过检：目标剧的角色名、专有名词、标志性场景逐个 grep 零命中；
- 去小说化过检：心理描写检查命令零命中，情绪全部外化为动作/神态/台词/环境细节；
- 节奏标注齐：3 秒钩子、每 15–20 秒反转或信息增量、集尾悬念各就各位；
- 3 个备选剧名 + logline + 后 3 集分集钩子齐备。

## 4 制作（成片）

制作链由已装技能承接，本环节只做编排与验收：

`$short-drama` 建项 → 需要分集大纲时 `$short-drama-develop` → 每集 `$short-drama-assets` → `$short-drama-image-prompts` → `$short-drama-storyboard` → `$short-drama-video-prompts` → `$short-drama-produce`（付费生成，先预览后确认）→ `$short-drama-edit` 出片 → `$short-drama-review` 把关。

完成标准：
- 五份核心文档（剧本/视觉设定/分镜/图片提示词/视频提示词）齐备，`creator_markdown_check.py` 全量通过；
- `$short-drama-review` 问题单逐条清零，或用户明示接受带病项；
- 成片落 `制作成果/成片/`；剪辑需要 `ffmpeg`/`ffprobe` 在 PATH。

发布动作由用户完成。发布后请用户提供平台、发布时间与每集链接，记入 `项目开发/数据复盘.md` 表头，进入复盘。

## 5 复盘（分析数据）

目标：把数据翻译成下一部剧、下一集的具体改动。

指标定义、行业基准、归因映射表见 `references/analytics.md`。数据来自平台后台（用户提供导出或截图），按参考文件中的表格填入 `项目开发/数据复盘.md`。

完成标准：
- 逐集指标表填齐：完播率、3 秒跳出率、追更率、互动率；投流时含 ROI；
- 每项指标对照基准表给出达标判定；
- 流失点归因到具体集的具体节拍（哪句钩子没接住、哪个反转间隔超时）；
- ≥1 条可执行迭代动作写回：改核心思路卡片的换壳方案或钩子设计，或改剧本节奏；写回后循环回拆骨或编剧环节。
